# NEST 自动排版插件 — 配置与部署说明

> 版本：`NEST v20260731-0900`  
> 源文件：`lsp_plugin/nest.lsp`  
> 目标环境：**Windows 7 32位 + AutoCAD 2007**（也兼容同代支持 LISP/ActiveX 的 CAD）

---

## 1. 这是什么

在 **当前已打开的 DWG/DXF** 里一键排版：

1. 输入命令 → 框选图形  
2. 自动识别「外框 + 内部孔/弧」为整体  
3. 按 **行优先** 排入 600×850 板材  
4. **原图移走**（不是复制重画），板框画在选择区右侧  

**零外部依赖**：不需要 Python、不需要 COM 写回、不装其它软件。

---

## 2. 文件怎么放（非常重要）

| 项目 | 要求 | 原因 |
|------|------|------|
| 编码 | **GBK（ANSI）** | CAD2007 加载 UTF-8 的 LISP 会乱码/失败 |
| 路径 | **纯英文短路径** | 中文路径 APPLOAD/`load` 常静默失败 |
| 推荐位置 | `D:\NEST.LSP` | 所有工位统一，好记 |

仓库里的 `lsp_plugin/nest.lsp` 已是 GBK 成品。部署时**原样拷贝**到目标机，不要用记事本「另存为 UTF-8」。

```
正确：  D:\NEST.LSP
正确：  C:\CAD\NEST.LSP
错误：  D:\自动排版\nest.lsp          ← 路径有中文
错误：  用 VS Code 另存成 UTF-8 后再给 CAD 加载
```

---

## 3. 单机安装（首次）

### 3.1 拷贝

把 `nest.lsp` 复制为：

```
D:\NEST.LSP
```

### 3.2 加载

打开 AutoCAD 2007，命令行输入（**正斜杠 `/` + 双引号**）：

```lisp
(load "D:/NEST.LSP")
```

成功应看到：

```
[NEST] loaded. Command: NS  (or NEST)
```

### 3.3 使用

| 命令 | 说明 |
|------|------|
| **`NS`** | 推荐，两键启动 |
| `NEST` | 完整命令名，效果相同 |

流程：`NS` → 框选要排的图形 → 回车 → 等待完成提示。

### 3.4 开机自动加载（可选，每台做一次）

1. 命令行：`APPLOAD`  
2. 选中 `D:\NEST.LSP`  
3. **启动组 / Contents** → **添加** → 加入该文件  
4. 确定  

之后每次开 CAD 自动加载，直接输入 `NS` 即可。

## 4. 多台电脑批量部署

1. 从 GitHub 拉仓库，或只拷 `lsp_plugin/nest.lsp`  
2. 每台机器统一放到 **`D:\NEST.LSP`**  
3. 首次 `(load "D:/NEST.LSP")`，建议再做成启动组自动加载  
4. 工位可贴条：

```
加载（仅首次/更新后）： (load "D:/NEST.LSP")
使用： NS  → 框选图形
```

**环境核对表**

| 项 | 要求 |
|----|------|
| 系统 | Win7 32位 ✅ / 64位也可 |
| CAD | AutoCAD 2007（需支持 AutoLISP + ActiveX/`vlax`） |
| 网络/Python | 不需要 |
| 权限 | 对 `D:\` 有写权限（或改放到有写权限的英文目录） |

## 5. 默认参数（可改）

加载插件后、运行 `NS` **之前**，可在命令行用 `setq` 临时修改。  
要永久改：编辑 `nest.lsp` 顶部对应变量，保存为 **GBK**，再重新 `(load ...)`。

| 变量 | 默认值 | 含义 |
|------|--------|------|
| `*NEST-BOARD-W*` | `600.0` | 板材宽度 mm |
| `*NEST-BOARD-H*` | `850.0` | 板材高度 mm |
| `*NEST-SPACING*` | `10.0` | 零件间距 mm |
| `*NEST-MARGIN*` | `10.0` | 板边距 mm |
| `*NEST-LAYER*` | `"NEST-OUT"` | 板框所在图层名 |
| `*NEST-LAYER-COLOR*` | `1` | 板框颜色（1=红） |
| `*NEST-OFFSET-X*` | `50.0` | 结果相对选择区右侧的 X 偏移 |
| `*NEST-OFFSET-Y*` | `0.0` | 结果 Y 偏移 |
| `*NEST-BOARD-GAP*` | `50.0` | 多板之间水平间距 |
| `*NEST-MAX-ROW-W*` | `6000.0` | 板材横排总宽上限，超出则换行 |
| `*NEST-ROW-GAP*` | `50.0` | 板材换行后的行距 |
| `*NEST-CLUSTER-GAP*` | `5.0` | 整体识别：图元间隙 ≤ 此值则合并为一件 |
| `*NEST-CONTAIN-TOL*` | `2.0` | 包含判定容差 mm |
| `*NEST-MIN-AREA*` | `0.5` | 过滤碎线：bbox 面积小于此值跳过（mm²） |

**示例：间距改成 5mm 再排**

```lisp
(setq *NEST-SPACING* 5.0)
NS
```

**示例：板材改成 500×700**

```lisp
(setq *NEST-BOARD-W* 500.0)
(setq *NEST-BOARD-H* 700.0)
NS
```

## 6. 算法行为（方便对照结果）

| 项目 | 当前行为 |
|------|----------|
| 整体识别 | 包围盒**包含** 或 **中心落入** 或 **间隙 ≤ 5mm** → 并成一件 |
| 超大剥离 | 任一边 > 板可用区（600−20 / 850−20）的图元不参与父级合并 |
| 排样方向 | **行优先**（先沿 X 填满一行，再往上） |
| 旋转 | 试 0° / 90°，能放下即可 |
| 输出方式 | `vla-move` / `vla-rotate` **移动原实体**，原位置消失 |
| 板框 | 新建图层 `NEST-OUT` 上画矩形 |
| 跳过类型 | TEXT / MTEXT / DIMENSION / LEADER 等标注类（不参与排版） |

框选时：尽量框住完整零件；标注可一起框，碎线会被面积过滤，文字/尺寸类型会被跳过。

## 7. 正常运行时的命令行输出

```
===== NEST START =====
Select objects:
[NEST] selected 108
[NEST] extracted 100
[NEST] cluster input 100
  unit 1: 274.0x360.0 (80 ents)
  unit 2: ...
[NEST] units = 4
[NEST] packing...
[NEST] placed 4
[NEST] DONE: 4 parts -> 1 boards
===== NEST END =====
```

关注：

- `units = N`：应接近「零件件数」，而不是上百个碎块  
- `DONE: X parts -> Y boards`：排入件数与板数

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 输入 `NS` 提示未知命令 | 未加载。执行 `(load "D:/NEST.LSP")` |
| 加载无反应 / 报错 | 路径有中文，或文件被存成 UTF-8。用仓库 GBK 版覆盖 `D:\NEST.LSP` |
| 加载后中文乱码但命令可用 | 可忽略；当前提示已改为英文 |
| 零件被拆开排 | 看 `units=` 是否过大；可适当增大 `*NEST-CLUSTER-GAP*`（如 8.0）后重载再试 |
| 小孔（约 3mm）丢失 | 不要用「长度过滤」；当前按面积 `< 0.5` 过滤，3mm 孔应保留。若仍丢，查是否被标成 TEXT 等跳过类型 |
| 部分图形过大跳过 | 单件超过约 580×830 无法入板，属预期 |
| 改完 lsp 没变化 | CAD 仍用内存旧版，必须重新 `(load "D:/NEST.LSP")` |
| 从 Git 更新后 | 覆盖 `D:\NEST.LSP` → 再 `load` 一次 |

## 9. 从本仓库更新插件

```text
1. git pull   （或下载最新 nest.lsp）
2. 复制 lsp_plugin/nest.lsp  →  D:\NEST.LSP   （覆盖）
3. CAD 中： (load "D:/NEST.LSP")
4. 确认版本横幅 / 加载提示后使用 NS
```

开发修改流程（维护者）：

1. 改 `lsp_plugin/nest.lsp`（保持 **GBK** 保存）  
2. 同步拷到 `D:\NEST.LSP`  
3. CAD 里重新 load 测试  
4. 提交 Git  

若用 UTF-8 编辑器改完，**必须转回 GBK** 再给 CAD 用，例如 PowerShell：

```powershell
$utf8 = [System.Text.Encoding]::UTF8
$gbk  = [System.Text.Encoding]::GetEncoding('gb2312')
$t = $utf8.GetString([IO.File]::ReadAllBytes('路径\源.lsp'))
[IO.File]::WriteAllBytes('D:\NEST.LSP', $gbk.GetBytes($t))
```

## 10. 与旧 Python 方案的关系

| | Python 桌面版 | 本 LISP 插件 |
|--|---------------|--------------|
| 入口 | `python main.py` | CAD 内 `NS` |
| 环境 | 需 Python 依赖 | 仅 CAD2007 |
| 写回 | 导出新 DXF | 当前图直接移动 |
| 厚度分组 | 有 | 无（一次框选排一批） |
| 适用 | 有现代 Python 的机器 | **车间 Win7 32位六台** |

车间生产以 **本插件** 为准；Python 版保留作算法参考与离线诊断。
