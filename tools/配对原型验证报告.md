# 配对嵌合 原型验证 + LISP 移植报告

> 日期：2026-08-01
> 状态：**原型已跑通 + 已移植进 `lsp_plugin/nest.lsp`（GBK 同步 D:\NEST.LSP）**

---

## 0. 结论速览

- **配对嵌合可行且已移植**：复杂件（凹度大）旋转 180° 嵌合成超单元再排，省 10%~40% 面积。
- 实测：新月形件 109×81 配对后组合 bbox 167×76（省 ~18%），间距 ≥10mm、零重叠。
- 高脚杯/近矩形件收益≈0，被 8% 阈值自动跳过。
- 排样器本身未改；配对在 `nest-build-units` 之后、`nest-pack` 之前插入。

## 1. 原型做了什么

离线读取 DXF → 聚类成单元 → 对可配对件尝试 **旋转 180° 嵌合**（保留 10mm 间距）→
把收益达标的件融成"超单元" → 用与 LISP 一致的 bbox BLF 排样 →
用 shapely 对**真实轮廓**断言零重叠。

关键设计（吸取上次多边形碰撞失败的教训）：
- 配对在排样**之前**完成，排样器本身不动（当前稳定版 LISP 逻辑原样复刻）
- 嵌合滑动要求 **间距 >= 10mm**（A 外扩 sp 后再测相交），不依赖贪心 slide
- 变换基准与 `nest-move-unit` 一致：旋转绕 bbox 左下角、rot 时 x 位移加原始高
- 配对按 bbox 尺寸池 + 相邻池，避免 O(n²)；二分滑动代替网格扫描

## 2. 验证结果（QDG193264913.dxf）

### 只排"复杂件"（bbox 填充率 < 0.8，375 件）
| 指标 | 基线 bbox | 配对后 |
|------|-----------|--------|
| 板数 | 13 | **12**（省 1 板） |
| 利用率 | 71.5% | **74.6%**（+3.1pp） |
| 真实重叠 | 0 | **0** |
| 超单元 | — | 38 对 |
| 节省面积 | — | 172,048 mm²（占 bbox 面积 3.6%） |

### 全文件（含 3mm 小孔，1622 件）
利用率 82.9%，配对后板数不变（0 板）——因为该文件已被小孔填满，且大部分件近矩形。

## 3. 单类件嵌合收益（shapely 逐对测量）

| 形状 | bbox | 嵌合方式 | 组合 bbox 节省 |
|------|------|----------|---------------|
| 高脚杯 | ~250×95 | 旋转180 | ~5% |
| 弧形件(320顶点) | ~143×87 | 旋转180 | **~28%** |
| 新月形(80顶点) | ~109×81 | 旋转180 | **~41%** |

→ 结论：**对凹度大的件（弧形/新月/左右脚），配对收益显著；对高脚杯本身收益小。**
收益大小与"bbox 填充率"高度相关，所以原型默认只对 fill<0.8 的件配对。

## 4. 关键结论

1. **配对嵌合技术路线成立**：零重叠、间距达标、板数减少，且没有重蹈上次多边形碰撞
   的"重叠/混乱"覆辙。
2. **收益集中在大凹度件**：左右脚、弧形、新月形件（正是你反馈"无法使用"的复杂件）。
3. 阈值建议：配对收益 >= 8% 才成对（`--pair-win=8`），可调。
4. 全文件混排时收益被小孔件稀释，但实际生产是**框选一批同类件**排，
   此时收益会更接近"单类件"那栏（28%~41%）。

## 5. 移植 LISP（已完成）

2026-08-01 已移植进 `lsp_plugin/nest.lsp`，GBK 同步 `D:\NEST.LSP`。新增：

| 函数 | 作用 |
|------|------|
| `nest-seg-intersect` / `nest-pt-in-polygon` / `nest-poly-collide` | 多边形相交判定 |
| `nest-poly-dist` / `nest-poly-hit` | 精确最小距离，间距 < 1.3×sp 视为碰撞（采样余量） |
| `nest-curve-sample` / `nest-unit-spts` | 取单元最大 bbox 实体轮廓点（POLYLINE 取全部顶点后抽稀到 40） |
| `nest-pair-nest` / `nest-pair-slide` | 二分滑动找最小组合 bbox |
| `nest-pair-units` | 主配对：候选池+滑动窗口，收益≥8% 才成对，防卡死上限 |
| `nest-make-superunit` / `nest-move-superunit` | 生成/移动超单元（A 固定，B 旋转180° 到位） |
| `subseq-sorted` | 候选超限时按面积取前 N |

参数（`nest.lsp` 顶部，`setq` 可临时改）：
- `*NEST-PAIR-ENABLED*` T：总开关（想关配对置 nil）
- `*NEST-PAIR-WIN*` 8.0：配对收益阈值%
- `*NEST-PAIR-SAMPLES*` 40：轮廓采样点数
- `*NEST-PAIR-FILL-MAX*` 0.85：只对 bbox 填充率低于此值的复杂件配对
- `*NEST-PAIR-MAX-CAND*` 200 / `*NEST-PAIR-MAX-TRY*` 400：防 LISP 卡死

关键防坑（吸取上次多边形碰撞失败教训）：
1. **变换基准与 nest-move-unit 严格一致**：超单元内 A 固定在原点（其真实 bbox 左下角），
   B 旋转 180° 后按其真实 bbox 左下角偏移放置。
2. **cw/ch 用单元真实 bbox 尺寸**（不能用重采样点，否则低估导致重叠）。
3. **间距用精确最小距离**判定（非 buffer 近似），再乘 1.3 安全系数，保证 ≥10mm。
4. 超单元**整体不旋转**（配对朝向已定）。
5. 配对在 `nest-build-units` 之后、`nest-pack` 之前插入；排样器不动。

## 6. 用法

```bash
python tools/pair_prototype.py <file.dxf> --quick --complex-only
python tools/pair_prototype.py <file.dxf> --only-shapes=250x95
```

`--only-shapes=WxH` `--max-units=N`
